Edgway accepts Kong's `cors` configuration unchanged: the schema below is Kong's own. The plugin package's [README](https://github.com/scoobydrew83/edgway/blob/main/plugins/cors/README.md) lists what Edgway doesn't support.

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `config.credentials` | boolean |  | `false` | Flag to determine whether the `Access-Control-Allow-Credentials` header should be sent with `true` as the value. |
| `config.exposed_headers` | array of string |  |  | Value for the `Access-Control-Expose-Headers` header. If not specified, no custom headers are exposed. |
| `config.headers` | array of string |  |  | Value for the `Access-Control-Allow-Headers` header. |
| `config.max_age` | number |  |  | Indicates how long the results of the preflight request can be cached, in `seconds`. |
