Edgway accepts Kong's `http-log` configuration unchanged: the schema below is Kong's own. The plugin package's [README](https://github.com/scoobydrew83/edgway/blob/main/plugins/http-log/README.md) lists what Edgway doesn't support.

| Field | Type | Required | Default | Description |

| `config.content_type` | `"application/json"`, `"application/json; charset=utf-8"` |  | `"application/json"` | Indicates the type of data sent. The only available option is `application/json`. |
| `config.custom_fields_by_lua` | object |  |  | Lua code as a key-value map |
