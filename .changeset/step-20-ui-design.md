Edgway's own colors replace shadcn's neutral theme, in light and dark, with new `warning` and `success` tokens, all checked for WCAG contrast. The admin UI and the portal use IBM Plex Sans and Mono, self-hosted; the portal no longer loads Geist or Playfair Display from Google Fonts.

The admin UI shows a warning banner on every page while changes are staged ("N unpublished changes. The gateways still serve version V."), the sidebar's Publish item carries the count, and narrow screens keep a "N to publish" link in the header.

The portal says "rotate" for replacing a key, as the admin does (Zudoku's own "Roll key" button label is fixed in Zudoku).
